## Task III（进行中）— 四个 P0 收敛成一条执行链

用户给了一份 51 节的长指令，把 4 个 P0 收敛成：

```
API → Durable DB → {Conversation/Task/Execution | Command/Approval/Action}
    → {Agent Worker | Command Runner} → Lease + Fence → {Copilot SDK | Jira}
    → Reconciliation
```

前置条件（用户明确）：**SQLite + `DatabaseSync` 不适合直接开多副本**。所以分两层：
第一层现在改代码解决逻辑正确性；第二层（真启用多副本）迁 PostgreSQL，并把
Agent Worker 与 API Replica 拆开。本次**不**把 `node:sqlite` 换成 `pg`。
